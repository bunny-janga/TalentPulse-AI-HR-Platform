# What changed in this version

## 1. Neobrutalism redesign (whole UI)
Thick ink borders, hard offset shadows, flat saturated colour, dot-grid paper, chunky type. Light and dark themes (light is default), responsive down to phones (sidebar becomes a bottom tab bar), keyboard focus rings kept visible, `prefers-reduced-motion` respected.
Removed: glass blur, cursor-follower aura (re-rendered the whole shell on every mouse move), 3D tilt/magnetic effects, canvas constellation.

## 2. Security and privacy fixes (the important ones)
| Problem found | Fix |
|---|---|
| `/db` and `/db/query` were open to anyone, no login, and exposed password columns | Admin/Super Admin token required, read-only SQLite connection plus an authorizer that only allows SELECT; password columns always read as NULL |
| Login accepted hard-coded and case-insensitive passwords and a plaintext `initial_password` column | bcrypt check only. Plaintext column is wiped at startup. Demo logins are re-hashed at startup only when `DEMO_MODE=true` |
| "Password vault" showed every employee's plaintext password | Removed. Replaced by one-time temporary passwords (shown once, stored hashed) and an admin "Reset password" action |
| Any logged-in user could read every colleague's salary, band, rating, overtime | Redacted unless HR/Admin, the person themself (pay) or their manager (rating, overtime) |
| Policy upload used the client's filename (path traversal), no size or type limits | Random server-side name, extension and `%PDF` check, 8 MB cap, scanned PDFs rejected clearly |
| Hard-coded JWT secret in the repo, CORS `*`, server bound to 0.0.0.0 | Random per-install secret, explicit CORS list, localhost bind by default |
| `.env` with a live Gemini key was committed | Key blanked in the package. **Revoke that key**, and purge it from git history |

## 3. GenAI was not really running
* The model name `gemini-3.8-flash` does not exist, so every call failed silently and users got canned text selected by keyword. Now: configurable model (default `gemini-2.5-flash`), Gemini / Groq / OpenAI support, failures are logged, and every answer carries `mode: live | offline` shown in the UI.
* The offline helpdesk answer is now taken from the retrieved policy text instead of hard-coded sentences. Off-topic questions say "not covered".
* The review drafter parser never matched its own output, so growth areas and goals were always filler text. Fixed, and the fabricated filler is gone: offline mode only re-files the manager's own bullets.
* Draft endpoint used one id for both reviews and employees (wrong person on collision). New `POST /reviews/draft` takes `employee_id`.
* Prompts fence user text as data (prompt-injection hardening).

## 4. AI model honesty and explainability
* Per-person "top 3 reasons" now come from the model (reset each input to a healthy value, measure the drop), not fixed rules. Low-risk people no longer get invented positives.
* Company drivers on the dashboard were four hard-coded sentences; they are now counted from real scores.
* New: suggested retention actions per person.
* "Projected attrition" was the share of HIGH-band people; it is now the mean predicted probability.
* The dataset is synthetic (generated by a formula), so metrics are in-sample. Docs and UI say so.

## 5. Workflow bugs and missing requirements
* Leave: server counts Mon-Fri days itself, validates type/dates, blocks overlaps and over-quota requests, can't approve twice or approve your own; balances are real (`GET /leave/balance`) instead of hard-coded 12/10/15; managers can see their own requests; rejection requires a reason.
* Notifications are now created by real events (leave applied/decided, review published, new hire, 1-on-1 requested). Before, they were only seeded.
* Surveys: employees can finally answer (UI was missing), anonymous, `has_responded` flag, HR can create/close/reopen; AI themes field name mismatch fixed.
* Onboarding checklist UI added (it was an API with no screen); new hires get a default checklist.
* Reviews: employees never see drafts; duplicate cycle blocked; cycle list is current, not 2025; no self-review.
* Performance flags: "Schedule 1-on-1" was a fake toast; it now sends real notifications.
* Policies: read, upload PDF/text and delete from the UI.
* Admin metrics: headcount and department counts used different populations; fixed.
* Exit-interview AI has a screen now (HR only).
* Undefined CSS variables, missing `toast.warn`, missing `btn--xs`, missing icon, search `?q=` ignored: fixed.
